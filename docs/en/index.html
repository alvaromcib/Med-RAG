How it works

Four steps, all local.

Local PDF parsingPyMuPDF turns each page into Markdown and keeps the tables (for example the ACR appropriateness tables). Nothing leaves the machine: the first version used a cloud service.
Hybrid index in Qdrant512-token chunks tagged with guideline and page. Dense vectors (bge-small) for meaning and sparse ones (BM25) for exact terms such as “1p/19q” or “IDH”.
Answer with sourceLlamaIndex passes the 6 most relevant chunks to qwen2.5:7b (Ollama), which answers only from that context and says it doesn't know when the answer isn't there.
EvaluationQuestions whose reference answer and page were checked by hand in each guideline, plus questions from other specialties to see whether it abstains.
